# Чтение, отчёты и запросы

Порядок для агента: **discovery → карточка → выборка**. Не просите выгрузить всю конфигурацию.

1. `health` / `diag` — контур жив.
2. `guide` — если вопрос на естественном языке про типовую.
3. `meta_search` / `meta_list` — имя объекта.
4. `meta_describe` — поля **этой** базы.
5. `data_list` / `data_get` или `report` / `query`.

Фильтр `data_list` — JSON: `eq`, `gte`, `lte`, `id`, `contains`. Имена полей — с карточки, не из догадки модели.

Отчёт СКД: `POST /v1/report` (MCP `report`), форматы `json`, `markdown`, `csv`. Тяжёлое: `async: true` → `202`, затем `job_list` / `job_get`.

Произвольный запрос проходит валидатор: только `ВЫБРАТЬ`/`SELECT`, лимит строк 1–10000. Именованные запросы безопаснее — справочник `мкпИменованныеЗапросы`.

Сценарий «отгрузки за август»: `guide` → отчёт `Продажи` / `DemoSales` с `BeginDate`/`EndDate`, либо фильтр по дате на документе реализации.

Пресеты типовых: [skills](../skills.md).
