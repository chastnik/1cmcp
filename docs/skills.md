# Пресеты и навыки для типовых конфигураций

Пользователь спрашивает «покажи отчёт по продажам за август», а в метаданных УТ это `РеализацияТоваровУслуг`. Чтобы не плодить сотни MCP-инструментов и не заставлять консультанта заполнять словарь под каждый вопрос, в шлюзе лежат **пресеты** и один инструмент **`guide`**.

Подробный сценарий для агента: [`skills/1cmcp-typical/SKILL.md`](../skills/1cmcp-typical/SKILL.md). Решение: [ADR-0007](adr/0007-typical-presets-and-guide.md).

## Что это не делает

Это **не** обход прав 1С. Запись документов — только через dry-run и whitelist. «Отчёт по продажам» — `POST /v1/report` / MCP `report`. Если отчёта нет (404), fallback: выборка реализаций и сумма, с оговоркой, что это не СКД.

## Пресеты

| `ONEC_PRESET` | Конфигурация | Заказы в подсказках |
|---|---|---|
| `auto` (умолчание) | все словари; `guide` берёт имена УТ | `ЗаказКлиента` |
| `ut11` | Управление торговлей 11 | `ЗаказКлиента` |
| `ka2` | Комплексная автоматизация 2 (словарь УТ +) | `ЗаказКлиента` |
| `erp2` | ERP 2 (словарь УТ + производство) | `ЗаказКлиента` |
| `bp30` | Бухгалтерия 3.0 | `СчетНаОплатуПокупателю` |
| `none` | только словарь в 1С и живые метаданные | — |

Самописная база: `none` и заполните `мкпСемантическийСловарь`.

Имена в JSON — из **публичного** описания типовых на ИТС. Перед чтением агент всегда делает `meta_describe`.

## Как пользоваться в MCP

```text
Пользователь: сколько пришло заказов за март 2026?
Агент: guide("сколько пришло заказов за март 2026")
     → meta_describe(document, ЗаказКлиента)
     → data_list(..., filter={"Дата":{"gte":"2026-03-01","lte":"2026-03-31"}})
     → ответить количеством (и суммой, если нужно)
```

```text
Пользователь: покажи отчёт по продажам за август
Агент: guide(...) → report(Продажи или DemoSales) с BeginDate/EndDate
     при 404: РеализацияТоваровУслуг → выборка → сумма
```

Claude Desktop: добавьте в `env` `"ONEC_PRESET": "ut11"` (или `bp30`).

## Как пользоваться в REST

Поиск уже смешивает пресет:

```bash
curl -sS -H "Authorization: Bearer $TOKEN" \
  --get --data-urlencode "q=заказ" "$BASE/v1/meta/search"
```

На моке первым останется демо-объект, если он тоже матчится; подсказка `ЗаказКлиента` идёт следом с смыслом «проверьте describe».

Инструмент `guide` есть только в MCP (это плейбук, не данные 1С).

## Файлы в пакете

`gateway/src/onecmcp/presets/data/*.json` — ставятся вместе с `onecmcp`. Редактируйте их в git, не копируйте в каждую базу. При расхождении с конкретной доработкой типовой побеждает `meta_describe`.
