# Пилот 1cmcp

Инженер не из команды разработки ставит контур по [install.md](install.md) и этой странице. Ключ продукта не нужен.

Живую базу клиента этот репозиторий не поднимает. Три типовых контура пилота:

| Контур | `ONEC_PRESET` | Зачем |
|---|---|---|
| УТ 11 / КА 2 / ERP 2 | `ut11` / `ka2` / `erp2` | продажи, заказы, заявка на расход |
| Бухгалтерия 3.0 | `bp30` | счета, поступления, ОСВ |
| Самописная | `none` | только `мкпСемантическийСловарь` |

## День пилота

1. Расширение из `extension/src`, публикация `mcp`, роль `мкпДоступКоннектора`, отдельный пул лицензий 1С (ADR-0004).
2. Токен — обработка администрирования; plaintext один раз.
3. Шлюз рядом с 1С. `GET /diag` — `ok`, не `degraded`.
4. Пресет агента из [connect/](connect/README.md).
5. `GET /guide` — каталог. Прогнать три фразы: отчёт за период, заявка на расход (если УТ/ERP), «накладная из почты» (только dry-run, без проведения).
6. Заполнить словарь: строки `dictionary_seed` (публичные имена ИТС). На самописной базе — свои синонимы, не копировать УТ вслепую.
7. ACL: пустой = только read; запись — скоуп write и whitelist.

Критерий: агент отвечает на вопрос пилота без правки кода шлюза.
