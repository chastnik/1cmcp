# Стенды фазы 0

Критерий готовности Ф0: пустое расширение собирается, ставится на четыре базы и отвечает на `GET /v1/health`.

| Стенд | Назначение |
|---|---|
| УТ 11 | Контур первой недели, замер лицензии на сеанс HTTP-сервиса |
| ERP 2 | Объём метаданных, проверка discovery |
| БП 3.0 | Типовая бухгалтерия, другая структура справочников |
| Самописная база клиента | Отсутствие зависимости от БСП и типовых подсистем |

Платформа: 8.3.20 или новее. Расширение — `AddOn` без заимствованных объектов, поэтому состав типовой конфигурации на установку не влияет.

Публикация: HTTP-сервис `мкпAPI`, корневой URL `mcp`. Проверка:

```
GET https://{host}/{ib}/hs/mcp/v1/health
```

Ожидается `200` и JSON контракта `Health`. 1С не публикуется в интернет: только шлюз, через VPN или mTLS.

Сборка `.cfe` из `extension/src` — Конфигуратор (`LoadConfigFromFiles` / загрузка расширения из файлов) либо 1C:EDT. В этом репозитории CI проверяет XML, префикс, UUID и контракт через мок; сборка двоичного `.cfe` подключается, когда на раннере появится платформа.
