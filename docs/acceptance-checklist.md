# Чек-лист приёмки

Используется в ревью и перед сборкой дистрибутива.

## Clean room

- [ ] Нет заимствований из сторонних `.cfe` / выгрузок аналогов
- [ ] Новые UUID сгенерированы в репозитории, не скопированы
- [ ] Имена объектов расширения начинаются с `мкп`
- [ ] Нет заимствованных объектов типовой конфигурации без отдельного ADR

## Контракт

- [ ] Изменение JSON согласовано с `specs/openapi.yaml`
- [ ] Ошибки — `application/problem+json`
- [ ] Ссылки сериализуются как `Ref` (`ref`, `id`, `presentation`)
- [ ] Выборка данных помечена `content_kind: data`

## Расширение

- [ ] Назначение `AddOn`, совместимость 8.3.20+
- [ ] HTTP-сервис отвечает на `GET /v1/health` кодом 200 и JSON контракта
- [ ] `ReuseSessions = AutoUse`
- [ ] Роль `мкпДоступКоннектора` минимальна

## Шлюз

- [ ] Не публикует 1С наружу: 1С только во внутренней сети / mTLS / VPN
- [ ] Тесты проходят без живой базы (мок слоя A)
- [ ] Покрытие `onecmcp` ≥ 90% (`./scripts/ci.sh`)
- [ ] MCP-инструменты discovery не выгружают всю конфигурацию целиком

## Репозиторий

- [ ] ADR добавлен, если менялась архитектура или контракт
- [ ] CI зелёный
- [ ] Секреты не в git
