# ADR 0011. Каталог сценариев и пресеты подключения агентов

- Статус: принято
- Дата: 2026-09-10
- Фаза: Ф5

## Контекст

Ф5 в плане — пилоты на живых ERP/БП/отраслевых базах, каталог сценариев «не API, а задача» и заявка в реестр ПО. Живые пилоты и подача в реестр не делаются из git. В репозитории должны появиться то, чем партнёрский офис пользуется без команды разработки: плейбуки, словари, JSON подключения.

Лицензирование продукта по-прежнему отложено (ADR-0010).

## Решение

1. Версия **0.6.0**. Каталог в `presets/data/scenarios.json`: чтение, отчёт СКД, запись только через `data_dry_run`.
2. Шлюз `GET /guide?q=` — тот же `guide`, что MCP. Без `q` — список сценариев. Секретов нет.
3. `dictionary_seed(preset)` — строки для `мкпСемантическийСловарь` из публичных имён типовых.
4. Пресеты подключения: `docs/connect/` (Claude Desktop, Cursor, n8n). Dify — OpenAPI шлюза.
5. Чек-листы пилота и реестра — документы, не отправка заявок.

## Последствия

- n8n и REST-агенты получают плейбук без MCP.
- «Первичка из почты» не пишет в 1С без confirm_token.
- Продажа через партнёра и пилот на стенде клиента остаются вне этого PR.
