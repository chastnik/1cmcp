# ADR 0003. Имена, префикс и UUID

- Статус: принято
- Дата: 2026-09-09
- Фаза: Ф0

## Контекст

Режим clean room требует собственных имён объектов метаданных, собственных UUID и отсутствия совпадений с чужими продуктами. Универсальное расширение не должно заимствовать объекты типовых конфигураций без крайней нужды: заимствования ломают штатные обновления у клиента.

## Решение

| | Значение |
|---|---|
| Имя расширения | `мкпКоннектор` |
| Префикс `NamePrefix` | `мкп` |
| Назначение | `AddOn` (дополнение) |
| Совместимость | `Version8_3_20` |
| Поставщик / разработчик | Стас Чашин, Stas@Chashin.pro |
| Корневой URL HTTP-сервиса | `mcp` |
| Пакет шлюза | `onecmcp` |
| Продуктовое имя | 1cmcp |

Все собственные объекты метаданных начинаются с `мкп`. UUID генерируются в этом репозитории и не копируются из чужих выгрузок.

Язык `Русский` **не заимствуется**: UUID языка различается между УТ, ERP и БП, а привязка по идентификаторам сломала бы установку на часть стендов. Расширение не содержит заимствованных объектов.

Состав Ф0:

- роль `мкпДоступКоннектора`
- общий модуль `мкпМаршрутизатор`
- HTTP-сервис `мкпAPI`

Имена справочников и регистров из плана (клиенты интеграции, правила доступа, журнал) получат тот же префикс в Ф1.

Состав Ф1:

- общие модули `мкпБезопасность`, `мкпСериализация`, `мкпИнтроспекция`, `мкпДанные`
- справочник `мкпКлиентыИнтеграции`
- регистры `мкпПравилаДоступа`, `мкпСемантическийСловарь`, `мкпЖурналВызовов`

Состав Ф2:

- общие модули `мкпЗапросы`, `мкпОтчёты`, `мкпЗадания`
- справочник `мкпИменованныеЗапросы`
- регистр `мкпСостоянияЗаданий`

Состав Ф3:

- общий модуль `мкпДействия`
- справочник `мкпДействияИнтеграции`
- регистры `мкпКлючиИдемпотентности`, `мкпТокеныПодтверждения`, `мкпОперацииСессии`

Состав Ф4:

- обработка `мкпАдминистрированиеКоннектора` (форма `Форма`)
- шаблон HTTP `GET /v1/diag`

Лицензирование продукта в состав расширения не входит.

## Последствия

- Установка на любую конфигурацию 8.3.20+ без заимствований.
- Коллизии имён с типовыми объектами исключены префиксом.
- Поиск чужих UUID в git — часть чек-листа приёмки.
