# Расширение и публикация

Контур с живой 1С: расширение `мкпКоннектор` + публикация HTTP-сервиса + шлюз во внутренней сети.

## Требования

- платформа **8.3.20+**, режим совместимости расширения `Version8_3_20`
- Конфигуратор с правом менять расширения
- Apache 2.4 или IIS
- клиентские лицензии: сеанс HTTP-сервиса занимает лицензию
- пользователь ИБ для публикации с ролью `мкпДоступКоннектора` **и** правами на прикладные объекты, которые должен видеть агент

Расширение — AddOn **без заимствованных** типовых объектов. Один каталог `extension/src` на УТ, ERP, БП и самописную базу.

## Загрузка

1. Создайте расширение с префиксом `мкп`, назначение «дополнение».
2. Загрузите конфигурацию из файлов `extension/src` (формат выгрузки 2.17).
3. Обновите конфигурацию БД.

Обработка **Администрирование коннектора**: токен (plaintext один раз), чеклист публикации, вызов `/v1/diag`. Не кликер IIS.

## Публикация

Корневой URL сервиса — `mcp`. Базовый URL шлюза:

```text
http(s)://{host}/{ib}/hs/mcp
```

без суффикса `/v1` — его добавляет контракт. Этот URL пишите в `ONEC_BASE_URL`.

!!! danger "Не публикуйте 1С в интернет"
    Снаружи только шлюз. Между шлюзом и 1С — LAN, VPN или mTLS.

Пошаговые экраны Конфигуратора и расчёт лицензий — в [обзоре установки](../install.md). Объекты метаданных — [справочник расширения](../reference/extension.md).
