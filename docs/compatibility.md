# Совместимость 1cmcp

Политика для внедренца. Лицензионный ключ продукта 1cmcp **не требуется**.

## Платформа 1С

| | |
|---|---|
| Минимум | **8.3.20** |
| Режим совместимости расширения | `Version8_3_20` |
| Назначение | дополнение (`AddOn`) |
| Заимствования типовых объектов | нет |

Оба режима информационной базы:

- **файловый** — разработка, маленькие стенды;
- **клиент-серверный** — пилот и прод.

HTTP-сервис `мкпAPI` одинаков в обоих режимах. Публикация на Apache 2.4 или IIS — штатный механизм платформы.

## Шлюз

- Python **3.12+**
- Docker Compose v2 или Helm 3 (чарт `deploy/helm/onecmcp`)
- Сеть до слоя A: внутренняя, VPN или mTLS. 1С в интернет не публикуется.

## Версии продукта

| Версия | Фаза | Содержание |
|---|---|---|
| 0.1.x | Ф0–Ф1 | каркас, чтение, интроспекция |
| 0.3.x | Ф2 | отчёты, запросы, `/v1/job` |
| 0.4.x | Ф3 | запись, dry-run, action, откат |
| **0.5.x** | **Ф4** | админ-обработка, `/v1/diag`, Compose/Helm |

Мажорная версия HTTP API — `v1`. Смена формы уже описанных ресурсов требует новой мажорной версии пути, не номера пакета.

## Клиентские лицензии 1С

Не путать с лицензией продукта. Каждый сеанс HTTP-сервиса занимает лицензию платформы. Модель: [ADR-0004](adr/0004-sessions-and-licenses.md), расчёт — [install.md §8](install.md).
