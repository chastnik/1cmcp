# Объекты расширения `мкпКоннектор`

Назначение: дополнение (`AddOn`), совместимость `Version8_3_20`, префикс `мкп`, без заимствований типовых объектов. Версия расширения совпадает с пакетом шлюза.

## Что настраивает консультант

| Объект | Тип | Назначение |
|---|---|---|
| `мкпКлиентыИнтеграции` | справочник | приложения: хеш токена, скоупы, пользователь ИБ, **лимиты суммы и количества**, активен |
| `мкпПравилаДоступа` | регистр сведений | матрица клиент × вид × имя × операция |
| `мкпИменованныеЗапросы` | справочник | безопасные запросы вместо произвольного текста |
| `мкпДействияИнтеграции` | справочник | whitelist методов конфигурации |
| `мкпСемантическийСловарь` | регистр сведений | синонимы и примеры для агента |
| `мкпАдминистрированиеКоннектора` | обработка | выпуск токена, чеклист публикации, самодиагностика |
| `мкпДоступКоннектора` | роль | минимальные права публикации |

Реквизиты клиентов и как задать лимиты: [клиенты](../admin/clients.md).

### `мкпИменованныеЗапросы`

| Реквизит | Смысл |
|---|---|
| `ТекстЗапроса` | текст на языке запросов 1С (выборка) |
| `СхемаПараметров` | описание параметров |
| `СхемаРезультата` | описание колонок |
| `ЛимитСтрок` | потолок строк этого запроса |
| `ТаймаутСекунд` | таймаут |
| `Активен` | выключенный запрос недоступен |

### `мкпДействияИнтеграции`

| Реквизит | Смысл |
|---|---|
| `ИмяДействия` | имя в `POST /v1/action` |
| `Разрешено` | нет → действие не исполняется |
| `ВидОбъекта` / `ИмяОбъекта` | к чему привязано |

## Служебное (не заполнять вручную)

| Объект | Зачем движку |
|---|---|
| `мкпЖурналВызовов` | кто, путь, код, длительность, `СсылкиJSON`; чтение API — `GET /v1/audit` |
| `мкпКлючиИдемпотентности` | повтор `Idempotency-Key` |
| `мкпТокеныПодтверждения` | TTL `confirm_token` |
| `мкпОперацииСессии` | откат по `X-Session-Id`; просмотр — `GET /v1/session/{id}` |
| `мкпСостоянияЗаданий` | `/v1/job`; список своего клиента — `GET /v1/job` |

Общие модули (`мкпМаршрутизатор`, `мкпБезопасность`, `мкпСериализация`, `мкпИнтроспекция`, `мкпДанные`, `мкпЗапросы`, `мкпОтчёты`, `мкпЗадания`, `мкпДействия`) и HTTP-сервис `мкпAPI` править на внедрении не нужно, кроме свойств сеанса из [диагностики](../admin/diag.md).
