# Реестр отечественного ПО

Заявку из этого репозитория **не подаём**. Здесь — что собрать, когда юридический контур будет готов.

Лицензирование самого 1cmcp не планируется (ADR-0010): в анкете нет серийника продукта. Клиентские лицензии платформы 1С — отдельная строка (ADR-0004).

## Что уже есть в git

- Исходники расширения и шлюза, clean room, ADR.
- Правообладатель в метаданных: Первый Бит.
- Совместимость 8.3.20+, документация внедренца.

## Что готовит юротдел / продукт, не git

- Карточка ПО, класс, назначение.
- Подтверждение прав на код (подписанные коммиты, этот репозиторий).
- Сведения о дистрибутиве (`.cfe` + образ шлюза), без DRM.
- Контакты правообладателя и ссылка на продукт.

Подача — отдельное решение заказчика продукта, не фаза разработки.
