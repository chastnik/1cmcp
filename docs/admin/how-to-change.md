# Как что-либо изменить

Сначала найдите ручку в таблице. Настройки шлюза с версии 0.11.0 меняют в **веб-консоли** (`http://шлюз:8000` → Администрирование), у каждого поля подсказка «?». Полные умолчания — в [справочнике настроек](../reference/settings.md).

## Я хочу…

| Задача | Где менять | Перезапуск |
|---|---|---|
| Открыть справочник API и MCP | веб-консоль `/` | не нужен |
| Подключить базу 1С | консоль → Базы 1С | не нужен |
| Сменить секрет подключения к базе | новый токен в обработке 1С, затем консоль → Базы 1С | не нужен |
| Завести оператора консоли | консоль → Операторы | не нужен |
| Запретить агенту запись дороже N ₽ | `мкпКлиентыИнтеграции.ЛимитСуммы` | не нужен |
| Запретить слишком много строк/штук | `ЛимитКоличества` | не нужен |
| Отключить агента | `Активен = нет` | не нужен |
| Дать запись только на один документ | скоуп `write` + строка `мкпПравилаДоступа` | не нужен |
| Подсказки УТ вместо БП | консоль → пресет | не нужен |
| Две базы на одном шлюзе | консоль → Базы 1С + `X-Tenant` | не нужен |
| Реже ходить в `/v1/meta` | консоль → TTL кэша meta | не нужен |
| Не кэшировать meta | TTL = 0 в консоли | не нужен |
| Снизить частоту запросов снаружи | консоль → лимит запросов | не нужен |
| Выключить rate limit | лимит = 0 в консоли | не нужен |
| Сменить путь MCP HTTP | консоль → путь MCP | шлюз |
| Слушать другой порт REST | `GATEWAY_PORT` или `serve --port` | шлюз |
| Отправлять трассы | консоль → OTLP + extra `otel` | шлюз |
| Добавить синоним «отгрузка» | регистр `мкпСемантическийСловарь` | кэш meta истечёт сам |
| Разрешить именованный запрос | справочник `мкпИменованныеЗапросы` | не нужен |
| Разрешить метод конфигурации | `мкпДействияИнтеграции` | не нужен |
| Сменить таймаут до 1С | консоль → настройки / база | не нужен |
| Сменить образ шлюза | Helm `image.tag` / Compose rebuild | выкат |
| Число подов | Helm `replicaCount` | выкат |
| Не занимать лицензии слишком долго | `SessionMaxAge` у `мкпAPI` | обновить расширение / сеансы |
| Увеличить жизнь `confirm_token` | вшитые 600 с, не env | патч мока/расширения, см. [константы](../reference/settings.md) |
| Поднять потолок строк `query` | вшитые 1–10000 | патч валидатора; именованный запрос — `ЛимитСтрок` |
| Посмотреть, что вызывал агент | `GET /v1/audit` / MCP `audit_list` | не нужен; в 1С — регистр `мкпЖурналВызовов` |
| Посмотреть операции сессии до отката | `GET /v1/session/{id}` / MCP `session_get` | не нужен |
| Посмотреть свои фоновые задания | `GET /v1/job` / MCP `job_list` | не нужен; в 1С — регистр `мкпСостоянияЗаданий` |

## Порядок безопасной смены токена

1. Сгенерировать новый plaintext в обработке.
2. Убедиться, что новый элемент **Активен**, скоупы те же.
3. Обновить токен подключения в веб-консоли шлюза (Администрирование → Базы 1С).
4. Проверить `GET /v1/meta` с новым Bearer.
5. Старый элемент: **Активен = нет**.

Не храните plaintext в справочнике и в git.
