# Как что-либо изменить

Сначала найдите ручку в таблице, затем откройте карточку справочника или переменную окружения. Полные умолчания — в [справочнике настроек](../reference/settings.md).

## Я хочу…

| Задача | Где менять | Перезапуск |
|---|---|---|
| Подключить другую базу 1С | `ONEC_BASE_URL` | шлюз / MCP |
| Сменить секрет агента | новый токен в обработке, затем `ONEC_TOKEN` | шлюз / MCP |
| Запретить агенту запись дороже N ₽ | `мкпКлиентыИнтеграции.ЛимитСуммы` | не нужен |
| Запретить слишком много строк/штук | `ЛимитКоличества` | не нужен |
| Отключить агента | `Активен = нет` | не нужен |
| Дать запись только на один документ | скоуп `write` + строка `мкпПравилаДоступа` | не нужен |
| Подсказки УТ вместо БП | `ONEC_PRESET` | шлюз / MCP |
| Две базы на одном шлюзе | `ONEC_TENANTS` + `X-Tenant` | шлюз |
| Реже ходить в `/v1/meta` | `META_CACHE_TTL_SECONDS` | шлюз |
| Не кэшировать meta | `META_CACHE_TTL_SECONDS=0` | шлюз |
| Снизить частоту запросов снаружи | `RATE_LIMIT_PER_MINUTE` | шлюз |
| Выключить rate limit | `RATE_LIMIT_PER_MINUTE=0` | шлюз |
| Сменить путь MCP HTTP | `MCP_HTTP_PATH` или `--path` | шлюз / `mcp --transport streamable-http` |
| Слушать другой порт REST | `GATEWAY_PORT` или `serve --port` | шлюз |
| Отправлять трассы | `OTEL_EXPORTER_OTLP_ENDPOINT` + extra `otel` | шлюз |
| Добавить синоним «отгрузка» | регистр `мкпСемантическийСловарь` | кэш meta истечёт сам |
| Разрешить именованный запрос | справочник `мкпИменованныеЗапросы` | не нужен |
| Разрешить метод конфигурации | `мкпДействияИнтеграции` | не нужен |
| Сменить таймаут до 1С | `ONEC_TIMEOUT_SECONDS` | шлюз |
| Сменить образ шлюза | Helm `image.tag` / Compose rebuild | выкат |
| Число подов | Helm `replicaCount` | выкат |
| Не занимать лицензии слишком долго | `SessionMaxAge` у `мкпAPI` | обновить расширение / сеансы |
| Увеличить жизнь `confirm_token` | вшитые 600 с, не env | патч мока/расширения, см. [константы](../reference/settings.md) |
| Поднять потолок строк `query` | вшитые 1–10000 | патч валидатора; именованный запрос — `ЛимитСтрок` |

## Порядок безопасной смены токена

1. Сгенерировать новый plaintext в обработке.
2. Убедиться, что новый элемент **Активен**, скоупы те же.
3. Обновить `ONEC_TOKEN` у шлюза и MCP, перезапустить их.
4. Проверить `GET /v1/meta` с новым Bearer.
5. Старый элемент: **Активен = нет**.

Не храните plaintext в справочнике и в git.
